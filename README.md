## 🧠 Overview

ScoreSense is an ML-powered web application built with Streamlit that predicts student performance based on lifestyle and academic factors like study hours, attendance, sleep, and more.

It provides:

* 🎯 Real-time score prediction
* 🚗 Speedometer (gauge) visualization
* 📊 Interactive dashboard
* 🧠 Smart insights & suggestions

---

## ⚙️ Features

* 📚 Input-based performance prediction
* 📊 Visual dashboard with graphs
* 🚗 Speedometer-style score display
* 🧠 Personalized feedback system
* 🌙 Clean and modern UI

## ▶️ How to Run Locally

1. Clone the repository:

```
git clone https://github.com/your-username/scoresense.git
cd scoresense
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Run the app:

```
streamlit run app.py
```
